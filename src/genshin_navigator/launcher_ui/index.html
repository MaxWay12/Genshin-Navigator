Продолжить со старой версии

Выберите старую распакованную папку Navigator. Настройки, карты, подсказки и прогресс будут скопированы. Исходная установка сохранится.

Доступно только для чистой новой установки. В HoYoLAB нужно будет войти заново. Диагностика и старые резервные копии останутся в исходной папке.



Управление в игре
Num4/6 — цель · Num2 — пропустить · удержание Num5 — собрано · Num8 — отмена · Num7 — подсказка · Num1/3 — страницы · Num0 — карта · NumDecimal — закрепить HUD · Num9 — выход.
Глобальные клавиши требуют одинакового уровня прав Navigator и игры.


Новая версия без потери старой
Обновление готовится в новой пустой папке. Старую установку не удаляем. В HoYoLAB потребуется повторный вход.


Данные выбранного региона
Регион выбирается на вкладке «Запуск». Импорт изменяет только локальный прогресс; отправка в HoYoLAB остаётся ручной.


HoYoLAB · ручная синхронизация


Регион выбирается на вкладке «Запуск». Синхронизируются отметки карты, не реальное состояние игрового мира. Диковинки и ориентиры не отправляются.






Удалённые отметки автоматически не снимаются. При ошибке сети локальный GPS продолжает работать.


Планы сбора · регион со вкладки «Запуск»











Порядок сбора — не пеший маршрут. Изменённый порядок начинает план заново. Управление применяется при запуске GPS.


Прогресс каталога Navigator — не процент исследования игры


Настройки применяются при запуске GPS. Окно запуска закроется, чтобы освободить ресурсы.
