# Genshin Navigator v0.1.3-alpha — release candidate

Not yet approved for public release. Full Sumeru remains experimental.

- Launcher offers Sumeru forests, desert and available underground overlays.
- Public metadata supplies atlas revision and underground membership evidence.
- Existing official POI IDs preserve collected, remote-ignore and cached hints.
- The original desert configuration is retained; use the launcher for full Sumeru.

Update into a clean folder. Use the launcher's transfer tab before creating settings or downloading maps. Close the old GPS first. Authentication is not transferred.

Coverage and outstanding manual acceptance are documented in `docs/v013-validation.md`.
No routing, new object categories or automatic progress sync are included.
