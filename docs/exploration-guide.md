# Исследование мира в 0.2.0-alpha

Это инструкция для локального кандидата. Мондштадт, Драконий хребет и Сумеру
экспериментальные: наличие карты не означает проверку каждого участка в игре.

## Обновление и категории

Распакуйте кандидат в новую папку. В «Переносе» выберите старую установку,
завершите её GPS и подтвердите preview. Старые файлы не удаляются. Профиль
HoYoLAB не переносится: войдите повторно. Перед миграцией SQLite создаётся backup.

После переноса откройте «Обслуживание → Обновить каталог объектов» для каждого
используемого региона. Это публичная загрузка POI, не синхронизация аккаунта и не
повторная загрузка карт. На вкладке запуска включите нужные категории и сохраните.
Новый регион сначала требует «Подготовить данные».

- Сундуки, окулы, агаты и испытания используют постоянные отметки.
- Диковинки отмечаются только в текущей вылазке. «Сбор → Новая вылазка» сбрасывает
  только их. Время возрождения не рассчитывается; в HoYoLAB они не отправляются.
- Для телепортов и статуй действие называется «Посетил». Оно не утверждает, что
  объект активирован в игре, и не создаёт постоянной collected-отметки.

## Карта

Откройте карту Num0 / Ctrl+Alt+M, разблокируйте NumDecimal / Ctrl+Alt+L.
Колесо увеличивает карту под курсором, перетаскивание выключает слежение.
Внизу: сброс, к игроку, к цели, явное слежение и запись прогулки.

Справа находятся страницы по 20 объектов, состояния, поиск и переключатели
категории/слоя. Нажмите строку поиска, введите ID или вставьте текст через Ctrl+V;
Enter завершает ввод. Повторные нажатия «Слой»/«Категория» перебирают варианты.
Просматриваемый слой не меняет локализацию. При LOST карту можно изучать, но
выбор навигационной цели и актуальные расстояния недоступны.

Кластеры приближаются по клику, а совпавшие точки появляются в списке. Shift+клик
по строке/маркеру добавляет точку в текущий план; Shift+клик по группе добавляет
её точки. «План из списка» создаёт новый план текущего фильтра. Пунктир означает
только порядок сбора, а не подтверждённый проход.

## Планы

В launcher → «Сбор» загрузите каталог. Выберите слой, найдите объекты и добавьте
их в редактор. Порядок меняется перестановкой строк ID, удаление — удалением строки.
Можно добавить весь фильтр или получить отдельный preview порядка по прямой
близости. Сохранение и включение плана — разные действия.

План всегда относится к одному пространству. Collected/«Посетил» переводят к
следующему пункту; skip действует на текущий запуск. Undo восстанавливает действие
и шаг только в текущей сессии. После перезапуска сохраняются план и шаг, но не
история undo. Недоступные ID остаются в документе. Изменённый вручную порядок
начинается заново. Есть отдельные экспорт/импорт с preview; импорт не перезаписывает
существующий план по ID. «Свободный выбор» выключает план явно.

## Подсказки и HoYoLAB

В раскрытой карточке колесо над изображением масштабирует его, перетаскивание
сдвигает, «Сброс» возвращает исходный вид. Стрелки под изображением переключают
галерею, только если публичный ответ действительно содержал несколько изображений.
Колесо над текстом и прежние клавиши перелистывают текст. HoYoLAB и ссылки в тексте
открываются только по клику. Для мыши окно должно быть разблокировано.

Дополнительное изображение загружается при выборе. Уже загруженные материалы
доступны офлайн; общий кэш ограничен 256 МБ. LRU может удалить старые изображения,
поэтому это кэш, а не вечный архив всех когда-либо просмотренных картинок.

В launcher → HoYoLAB доступны вход, выход, проверка и ручной preview pull/push.
Применение требует отдельного подтверждения. Отмена не изменяет прогресс.

## Прогулки и экспериментальный граф

Запись включается только вручную из трея/карты; индикатор REC остаётся видимым.
Записывайте пешее движение. При потере позиции и скачках создаются разрывы;
программа не распознаёт полёт, плавание, лазание или падение автоматически.

После остановки GPS откройте launcher → «Прогулки» → «Обновить».
Выберите запись и нажмите «Просмотр». Цвета обозначают сегменты, квадрат — начало,
стрелка — направление. Снимите флажки неподходящих сегментов, задайте начало/конец
по секундам и сохраните разметку. Исходный журнал не меняется. Экспорт содержит
координаты оставленных сегментов, но не снимки, авторизацию, имя компьютера или
пути. Импорт всегда получает новый ID и статус «не проверено».

Для проверки графа выберите Ctrl+кликом несколько вручную проверенных прогулок
одного пространства. «Предпросмотр графа» не создаёт соединений автоматически.
Подтверждайте только физически проверенные переходы и только в указанном направлении.
Для разъединения удалите пару ID из редактора соединений и пересоберите preview.
Клики по узлам заполняют старт/цель. Путь считается по направленным записанным
рёбрам; отсутствие пути — корректный результат. Длина указана в world units.

Сохранённый граф можно открыть повторно. Если исходные записи или разметка
изменились, старая версия отклоняется; данные не удаляются.

**Ведение по графу в этом кандидате отключено.** Три игровые прогулки и пять
пилотных маршрутов ещё не приняты. Запись, разметка, обмен и лабораторная проверка
графа доступны, обычная прямая навигация продолжает работать. Граф не исправляет
координаты локализатора. Сервера сообщества и автоматической отправки нет.
