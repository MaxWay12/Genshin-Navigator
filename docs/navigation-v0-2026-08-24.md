# Navigation v0 baseline — 2026-08-24

Navigation v0 превращает отдельное topmost-окно отладочной карты в пассивный GPS.
Оверлей, маршрутизация, SQLite и синхронизация с HoYoLAB в этот этап не входят.

## Реализовано

- официальный каталог Фонтейна содержит линейные метрики поверхности и 59 этажей;
- старый каталог без метрик продолжает загружаться и не выдаёт пиксели за метры;
- `calibrate-distance` собирает три поверхностных замера 100–300 м;
- коэффициент выбирается медианой и принимается только при отклонении каждого
  замера не более 10%;
- незавершённая или невалидная попытка пишет отдельный draft и не заменяет
  последнюю рабочую калибровку;
- цель выбирается на текущем слое и остаётся закреплённой при движении;
- `N/P/S/M/U` управляют целью, session skip, collected и undo;
- collected сохраняется атомарно, skip сбрасывается при закрытии приложения;
- для каждого слоя хранится отдельная выбранная цель;
- stale/LOST/ACQUIRING/RELOCATING замораживают направление и расстояние;
- окно показывает цель, слой, линию, north-up стрелку и приблизительную прямую
  2D-дистанцию после калибровки.

## Данные и тесты

Пересобранный локальный каталог HoYoLAB map version 6.8 содержит 750 POI:
407 поверхностных и 343 подземных. В нём 60 метрических пространств: поверхность
и 59 официальных этажей. Все 45 пространств, на которых есть выбранные POI,
обеспечены метрикой; остальные 15 этажей сохранены для будущих типов POI.

В чистом Python 3.12 окружении установлены зависимости из `requirements-lock.txt`,
проект установлен editable-пакетом и пройдены 58/58 unit tests. Добавлены проверки
метрик, неравномерного масштаба, отсутствующих метаданных, медианной калибровки,
защиты рабочей калибровки, sticky target, переключения целей, skip, collected/undo,
возврата между слоями и запрета cross-layer POI.

Регрессионные результаты локализации не изменились:

| Проверка | Результат |
| --- | --- |
| surface | 4/4, median 3.902 px, P95 3.959 px |
| multispot | 3/5, прежние два `not_enough_feature_matches` |
| underground | 3/3 правильных слоя |
| stationary surface | pass, false locks 0, jitter P95 0.041 px |
| surface teleport | pass, false locks 0, reacquire 1.5002 с |
| stationary floor78 | pass, false locks 0, jitter P95 0 px |
| surface → floor78 | правильный слой, 0 one-frame switches; прежний fail end-phase |

Сценарий `surface_walk` также сохраняет прежний fail по ошибочно размеченному
неподвижному хвосту (jitter P95 8.952 px). Matcher/tracker и пороги под новые
проверки не подстраивались.

## Ручная проверка

Для завершения этапа пользователю остаётся выполнить три реальных калибровочных
замера и проверить отдельное окно на поверхности, после телепорта и на `floor78`.
До валидной калибровки интерфейс намеренно показывает `uncalibrated`.
