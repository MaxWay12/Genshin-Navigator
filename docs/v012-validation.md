# Проверка v0.1.2-alpha

## Проверка CPU тестером — ожидает выполнения

Одинаковый двухминутный маршрут для balanced и low_cpu:
0–20 с стоять; 20–70 с двигаться; затем телепорт и загрузка; оставшееся время движение, последние 15 с стоять.
Записать CPU Navigator и игры по Диспетчеру задач, FPS игры, время CV в HUD, случаи LOST и время восстановления после телепорта.
Указать CPU, разрешение, Windows и режим. Не считать время загрузки потерей трекинга.

Сравнение с 0.1.0 запускать из отдельной копии установки и данных. Не использовать рабочую базу прогресса. Хранить результаты в datasets/local/benchmarks/v012/.
Не выдавать измерение времени CV за процент загрузки всего CPU.

## Ручная приёмка — требуется игра

- Чистый запуск → подготовка данных → настройка миникарты → GPS.
- Настройки в трее → изменение режима → запуск выбранного региона.
- Перенос реальной 0.1.1: collected, remote-ignore, blacklist, калибровки, hints и карты доступны; исходная установка не изменилась.
- Проверить оба набора клавиш с активной игрой и отсутствие процесса launcher после запуска GPS.

## Автоматическая проверка

Выполнено 2026-09-05: 206/206 unit-тестов проходят. Fontaine golden suite проходит: coverage surface teleport 98.51%, false locks 0, reacquire 1.50 с. Sumeru recovery suite: 4/4 обязательных сценария проходят, 4 известных failing-сценария остаются informational; этот набор проверяет восстановление, а не абсолютную точность позиции.

Перенос проверен на изолированном снимке реальной локальной установки: 2209 файлов, полное равенство строк всех таблиц SQLite, 1165 POI, 61 пространство, 9 записей progress, 33 подсказки и 33 изображения. Карты Фонтейна после переноса готовы. Это проверка снимка, а не прохождение в игре после переезда.

Окно WebView2 открыто на Windows, визуально проверены главный экран и вкладка переноса. Сквозная ручная проверка GPS в игре и CPU на компьютере тестера остаются незавершёнными.
