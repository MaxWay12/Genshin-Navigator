# v0.1.4-alpha — статус проверки

Статус: **публикация alpha одобрена пользователем с указанными ниже ограничениями**. Выпуск объединяет неопубликованную 0.1.3 и исправления/UX 0.1.4. Незавершённые проверки не считаются пройденными.

## Автоматические проверки

- Исходные 219 тестов прошли до изменений. Текущий набор: 244 теста, включая Unicode I/O, ROI, worker, список целей, обновление и кнопки HUD.
- Fontaine golden suite: PASS, surface teleport coverage 98.51%, reacquire 1.5002 с. Старый manifest не имеет координатных checkpoints; это регрессионный контроль, не полное доказательство точности.
- Sumeru legacy recovery suite: 4/4 обязательных PASS; четыре прежних informational-провала сохранены. Scope: recovery-only, без positional ground truth.
- Проверка синтаксиса JavaScript launcher: PASS.
- CV-пороги и replay-профили не менялись. Тесты worker отдельно проверяют отбрасывание результата после паузы и просроченные снимки.
- Обновление проверяется на синтетическом ZIP: неправильная SHA, пути за пределы архива, symlink/ADS, обрыв сети, нехватка места, отмена и прерванный перенос.
- Собранный EXE: `--version` → `genshin-navigator 0.1.4a1`, CLI help работает. Privacy audit сборки пройден.
- Реальный ZIP через UpdateService и изолированную папку с кириллицей: перенос 489 файлов установленной 0.1.3, 1512 POI и всех остальных строк SQLite без изменений. В этом источнике progress пуст, поэтому отдельно проверен снимок 0.1.2.
- Снимок 0.1.2: 2209 файлов, все строки базы сохранены, включая 9 progress, 33 hints, 33 hint assets, 2 sync runs и 3968 unknown remote. Хеши исходных файлов не изменились; auth не перенесён. Это проверка данных и EXE, не ручная игровая приёмка.
- Синтетический рендер панели целей визуально проверен: 20 строк, переключение страниц и читаемые русские подписи.
- Новый HUD визуально проверен на синтетических состояниях tracking/hold/LOST. Автотесты кнопок: одно действие на клик, блокировка, раннее отпускание/уход курсора, успешное удержание, отмена при потере фокуса/позиции или смене цели. Реальный Win32 mouse hold в игре остаётся частью ручной приёмки.

## Оставшиеся проверки alpha

- Проверить candidate ZIP: чистый запуск, подготовка региона, ROI preview, GPS, настройки через трей.
- Игровая проверка полной карты: разблокировка, клики, наложенные маркеры, страницы, sticky target, skip/restore, collected/undo и перезапуск.
- Пауза/телепорт/LOST не возвращают устаревшую навигацию; закрытие HUD не ждёт полного поиска.
- После проверенного переноса данных вручную открыть offline hints и проверить управление в игре. Прогресс для теста не синхронизировать с аккаунтом, если сундук не собран реально.
- Записать восемь full-Sumeru сценариев по example manifest, проверить gating KPI без изменения классификации провалов.
- Balanced/low_cpu: одинаковые записи и аппаратные замеры, включая UI responsiveness. Обычный replay пока не моделирует scheduling live-worker; его processing time нельзя выдавать за CPU live-приложения.
- Проверить обновление из настоящего опубликованного ZIP. Updater integration проверен на fixtures; это не заменяет ручную проверку скачивания и запуска опубликованного выпуска.

Сеть обновлений: публичный [GitHub Releases API](https://docs.github.com/en/rest/releases/releases#list-releases), без аккаунта/токенов. Release notes отображаются как текст. SHA-256 проверяет целостность, не является подписью бинарника.
