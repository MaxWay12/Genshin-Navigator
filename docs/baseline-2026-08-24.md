# Fontaine MVP baseline — 2026-08-24

Этот отчёт фиксирует контрольную точку до настройки matcher/tracker по новым
stateful-сценариям. Локальные карты, кадры и отчёты с покадровой диагностикой не
входят в Git.

## Среда

- Python 3.12
- NumPy 2.5.2
- opencv-python 4.14.0.94 (версия `cv2`: 4.14.0)
- Pillow 11.3.0

Проект собран wheel-пакетом и установлен в новое временное виртуальное окружение.
В нём пройдены все 39 тестов.

контрольной позиции.

## Stateful baseline

Инфраструктура recorder/replay и синтетический сценарий
`pause → reacquire → подтверждённая смена слоя` проходят тесты. Три реальные
последовательности ещё не записаны, поэтому их метрики не подменяются
синтетическими результатами:

1. 15 секунд движения по поверхности + 5 секунд стояния.
2. Стабильный трек → телепорт → загрузка → повторный захват.
3. Поверхность → известный подземный слой.

Для реальных последовательностей контрольные критерии: false locks = 0, нет
одно-кадрового переключения слоя, reacquire не дольше 3 секунд после появления
миникарты и P95 stationary jitter не выше 5 atlas-px.
