# Fontaine MVP baseline — 2026-08-24

Этот отчёт фиксирует контрольную точку до настройки matcher/tracker по новым
stateful-сценариям. Локальные карты, кадры и отчёты с покадровой диагностикой не
входят в Git.

## Среда

- Python 3.12
- NumPy 2.5.2
- opencv-python 4.14.0.94 (версия `cv2`: 4.14.0)
- Pillow 11.3.0

Проект собран wheel-пакетом и установлен в новое временное виртуальное окружение.
В нём пройдены все 40 тестов.

Подземный baseline сохранился 3/3; для одной пары проверяется слой без точной
контрольной позиции.

## Stateful baseline

Инфраструктура recorder/replay и синтетический сценарий
`pause → reacquire → подтверждённая смена слоя` проходят тесты. Реальные crop-кадры
и полные покадровые JSON-отчёты сохранены только локально.

| Сценарий | Результат | Главные метрики |
| --- | ---: | --- |
| Движение по поверхности | core pass | 0 false locks, layer accuracy 100%, acquire 0.10 с |
| Неподвижная поверхность | pass | coverage 98.99%, jitter P95 0.041 px |
| Телепорт по поверхности | pass | reacquire 1.50 с, 0 false locks, 0 однокадровых смен |
| Surface → Great Lake floor78 | transition pass, end-phase fail | floor78 подтверждён без ложного слоя; coverage на движении 71.15% |
| Неподвижный floor78 | pass | coverage 98.94%, jitter P95 0 px, acquire 0.10 с |

Две первые попытки совместить движение и неподвижный отрезок не дали валидной
оценки jitter: персонаж продолжал перемещаться в размеченном stationary-окне. Они
оставлены в локальном корпусе как последовательности движения, а jitter измерен
отдельными неподвижными записями без изменения порогов.

Все уверенные позиции имели правильный слой; false locks и однокадровые смены слоя
не обнаружены. Телепорт укладывается в критерий reacquire ≤ 3 секунд, а обе чистые
неподвижные записи — в P95 jitter ≤ 5 px. Измеренный риск следующего этапа —
периодические stale-кадры подземного matcher во время движения и перехода слоя.
