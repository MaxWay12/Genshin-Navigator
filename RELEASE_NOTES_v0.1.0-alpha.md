# Genshin Navigator v0.1.0-alpha

The portable package contains only Navigator code, configuration, documentation
and third-party license texts. It does not redistribute HoYoLAB maps, POI data or
point images. Region data is downloaded by the user into a local cache on first
launch after explicit confirmation.

Первая публичная alpha пассивного GPS-помощника для Genshin Impact. Navigator
анализирует только изображение миникарты: он не читает память игры, не внедряется
в процесс и не эмулирует клавиатуру или мышь.

## Что работает

- live-локализация и навигационный HUD для Фонтейна;
- поверхность и 59 известных подземных этажей Фонтейна;
- официальный каталог POI, выбор цели, skip, collected и undo;
- локальное хранение прогресса в SQLite и экспорт/импорт резервной копии;
- карточки официальных подсказок HoYoLAB с офлайн-кэшем;
- необязательная ручная additive-синхронизация отметок HoYoLAB;
- экспериментальная локализация поверхности пустыни Сумеру;
- обезличенные diagnostic bundles и воспроизводимые benchmark-сценарии.

## Установка

Распакуйте архив в обычную папку без прав администратора. Скопируйте
`config.example.json` в `config.json`, один раз укажите рамку миникарты и запустите
`Start-Fontaine.cmd`. Подробная инструкция и клавиши находятся в `README.md`.

## Статус регионов

- **Фонтейн:** основной поддерживаемый vertical slice.
- **Пустыня Сумеру:** экспериментальная локализация поверхности. POI включены,
  но качество хуже в пустых руинах и других областях с малым количеством деталей.
- Остальной Тейват пока не поддерживается.

## Известные ограничения

- Это alpha, а не гарантия точности: при сомнении трекер намеренно показывает
  `LOST`, а не выдаёт предположительную позицию.
- В пустынных руинах Сумеру возможны длительные потери сопровождения.
- Расстояние прямолинейное и не учитывает стены, высоту и входы в пещеры.
- Глобальные клавиши Windows могут потребовать одинакового уровня прав с игрой.
- HoYoLAB API недокументирован; его отказ не мешает офлайн-трекингу и локальному
  прогрессу.
- Синхронизируются отметки интерактивной карты, а не фактическое состояние мира.

## Проверка целостности

Рядом с ZIP находится файл `.sha256`. Сравните SHA-256 архива перед распаковкой.
