# v0.2.0-alpha — локальный кандидат на приёмку

Не опубликован. Полная игровая приёмка ещё не завершена.

- Экспериментальные Мондштадт и Драконий хребет, официальные категории объектов.
- SQLite v4, отдельные вылазки диковинок и постоянные планы сбора.
- Zoom/pan карты, поиск, кластеры, просмотр слоёв и создание плана.
- Галерея публичных подсказок с ленивой загрузкой и общим офлайн-кэшем.
- HoYoLAB login/status/preview/confirm в launcher, без автоматического sync.
- Ручная запись координат прогулок, разметка без изменения оригиналов, обмен JSON.
- Консервативный редактор соединений и лабораторный поиск направленного пути.
  **Живое ведение по графу отключено до ручного пилота.**

Обновляйтесь в новую папку через существующий мастер переноса. После переноса
обновите каталог на вкладке «Обслуживание», чтобы появились новые категории.
Карты, cookies, прогресс и личные записи в ZIP не входят. В HoYoLAB потребуется
повторный вход. Старая установка остаётся рабочей.

Инструкция: [исследование мира](docs/exploration-guide.md).
Проверки и ограничения: [v020-validation](docs/v020-validation.md).
