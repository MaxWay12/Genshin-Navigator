# Genshin Navigator v0.1.2-alpha

Окно запуска, настройки и перенос из предыдущей portable-версии.

- `Start-Navigator.cmd` или запуск EXE без аргументов открывает русскоязычное окно в стиле HUD.
- Выбор региона, подготовка карт, настройка миникарты, режим CPU, NumPad/Ctrl+Alt, размеры HUD и трей доступны без редактирования JSON.
- Перед запуском GPS окно закрывается и освобождает WebView2. Пункт «Настройки» в трее завершает GPS и возвращает окно запуска.
- Перенос из старой папки сохраняет карты, SQLite-прогресс, калибровки, blacklist и кэш подсказок. Требуется чистая новая установка и остановленный старый GPS.
- Исходная установка сохраняется; вход HoYoLAB нужно выполнить повторно. Внешние пути и ссылки блокируют перенос с объяснением.

Скачайте ZIP и SHA-256, распакуйте в доступную для записи папку. Для переноса сначала откройте вкладку «Перенос данных», до сохранения настроек и загрузки карт.

Для нового окна требуется Edge WebView2. Старые региональные CMD и CLI остаются доступны.

## Проверки и ограничения

Автоматические проверки описаны в `docs/v012-validation.md`. CV-пороги не изменялись.
Снижение CPU на компьютере тестера, сообщавшего о 60%, пока **не подтверждено**: замеры должны быть выполнены на его оборудовании.
Сумеру остаётся экспериментальным; маршрутизации вокруг препятствий нет.
