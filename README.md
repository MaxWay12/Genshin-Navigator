# Genshin Navigator

**Genshin Navigator v0.1.0-alpha** — бесплатный open-source GPS-помощник для исследования мира Genshin Impact.

Navigator анализирует изображение миникарты в реальном времени, определяет примерное положение игрока и показывает выбранную цель, направление и расстояние до неё в отдельном HUD.

Программа работает пассивно и не является модификацией клиента игры.

> **Alpha:** это ранняя публичная версия. Возможны ошибки локализации, временный `LOST` и проблемы совместимости с некоторыми конфигурациями Windows и игры.

## Как это работает

Navigator получает обычное изображение экрана Windows и анализирует только область миникарты.

Программа:

- не читает и не изменяет память Genshin Impact;
- не внедряется в процесс игры;
- не управляет персонажем;
- не эмулирует клавиатуру или мышь;
- не модифицирует игровые файлы;
- не устанавливает низкоуровневые клавиатурные хуки.

Глобальные горячие клавиши реализованы стандартным Windows `RegisterHotKey` и управляют только самим Navigator.

Genshin Navigator — независимый fan-made проект. Он не связан с HoYoverse/COGNOSPHERE и не утверждает, что использование сторонних инструментов официально разрешено правообладателем.

## Возможности v0.1.0-alpha

- live-локализация по миникарте и stateful tracking;
- состояния `TRACKING`, `ACQUIRING`, `RELOCATING` и `LOST`;
- поверхность и известные подземные этажи Фонтейна;
- экспериментальная локализация пустыни Сумеру;
- локально загружаемый каталог POI;
- выбор и удержание текущей цели;
- previous / next / skip / collected / undo;
- компактный HUD и полноэкранная карта;
- карточки подсказок интерактивной карты;
- локальный SQLite-прогресс;
- офлайн-кэш просмотренных подсказок;
- экспорт и импорт прогресса;
- необязательная ручная additive-синхронизация отметок HoYoLAB;
- diagnostic bundles для воспроизводимой диагностики проблем локализации.

## Поддерживаемые регионы

| Регион | Статус | Поддержка |
| --- | --- | --- |
| **Фонтейн** | Supported alpha | Поверхность, 59 подземных этажей, POI, HUD, hints, progress |
| **Сумеру — пустыня** | Experimental | Поверхность, POI, HUD, hints, local progress |

**Фонтейн** — основной поддерживаемый vertical slice текущей alpha.

**Сумеру** пока ограничен поверхностью пустыни и используется в том числе для проверки переносимости локализатора на другой визуальный домен.

В визуально бедных областях, особенно некоторых руинах, Navigator может временно перейти в `LOST`. Это намеренное поведение: при недостаточной уверенности трекер предпочитает потерять позицию, а не показывать уверенную неправильную координату.

## Системные требования

- Windows 10/11 x64;
- Genshin Impact в оконном или безрамочном режиме;
- Num Lock для стандартных горячих клавиш;
- рекомендуемая конфигурация для первой alpha: **1920×1080, Windows scaling 100%**;
- Microsoft Edge WebView2 Runtime — только для необязательной интеграции HoYoLAB.

Интернет требуется для первоначальной загрузки региональных данных, получения новых подсказок и синхронизации HoYoLAB. После настройки основная локализация и локальный прогресс могут работать без сети.

## Быстрый старт

1. Скачайте `GenshinNavigator-v0.1.0-alpha-windows-x64.zip` из Releases.
2. При желании проверьте опубликованный SHA-256.
3. Полностью распакуйте архив в обычную папку с правом записи.
4. Для Фонтейна запустите `Start-Fontaine.cmd`.
5. Для экспериментального Сумеру запустите `Start-Sumeru-Experimental.cmd`.
6. Подтвердите загрузку необходимых региональных данных при первом запуске.

**Не запускайте `GenshinNavigator.exe` непосредственно из ZIP.**

Navigator создаёт рядом с программой локальный каталог `datasets/local`, где находятся загруженные данные, пользовательский прогресс, кэш и другое локальное состояние.

### Региональные данные

Portable-архив намеренно **не содержит карты, POI, изображения подсказок и другие материалы HoYoLAB/HoYoverse**.

При первом запуске Navigator запрашивает подтверждение и загружает необходимые данные в локальный пользовательский кэш. Прерванная загрузка не должна заменять последний рабочий набор данных.

Загруженные сторонние материалы не становятся частью MIT-лицензии Genshin Navigator.

## Настройка миникарты

Готовая конфигурация рассчитана прежде всего на:

**1920×1080 / Windows scaling 100%**

Стандартная область миникарты:

```json
"roi": {
  "left": 57,
  "top": 19,
  "width": 216,
  "height": 216
}
