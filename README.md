# Genshin Navigator

В `v0.1.2-alpha` запускайте **Start-Navigator.cmd** или EXE без аргументов: выбор региона, загрузка карт, настройка миникарты и параметры HUD доступны в отдельном окне. Окно закрывается перед запуском GPS; вернуться можно через «Настройки» в трее. Для окна требуется Edge WebView2, прежние региональные CMD сохраняются.

Для обновления распакуйте новую версию в отдельную папку и сначала выберите **Перенос данных**. Укажите старую установку и подтвердите, что старый GPS закрыт. Переносятся карты, прогресс, настройки и подсказки; исходная папка сохраняется. В HoYoLAB потребуется новый вход. Если в новой папке уже созданы пользовательские настройки или данные, перенос блокируется: используйте чистую распаковку. Внешние пути и junction/symlink не переносятся.

**Genshin Navigator v0.1.1-alpha** — пассивный GPS-помощник для мира Genshin Impact.

Navigator анализирует изображение миникарты в реальном времени, определяет примерное положение игрока и показывает выбранную цель, направление и расстояние до неё в отдельном HUD.

Программа работает пассивно и не является модификацией клиента игры.

> **Alpha:** это ранняя публичная версия. Возможны ошибки локализации, временный `LOST` и проблемы совместимости с некоторыми конфигурациями Windows и игры.

## Как это работает

Navigator получает обычное изображение экрана Windows и анализирует область миникарты.

Программа:

- не читает и не изменяет память Genshin Impact;
- не внедряется в процесс игры;
- не управляет персонажем;
- не эмулирует клавиатуру или мышь;
- не модифицирует игровые файлы;
- не устанавливает низкоуровневые клавиатурные хуки.

Глобальные горячие клавиши реализованы стандартным Windows `RegisterHotKey` и управляют только самим Navigator.

Genshin Navigator — независимый fan-made проект. Он не связан с HoYoverse/COGNOSPHERE и не утверждает, что использование сторонних инструментов официально разрешено правообладателем.

## Возможности v0.1.0-alpha

- live-локализация по миникарте и stateful tracking;
- безопасные состояния `TRACKING`, `ACQUIRING`, `RELOCATING` и `LOST`;
- поверхность и подземные этажи Фонтейна;
- экспериментальная поверхность пустыни Сумеру;
- локально загружаемый каталог сундуков и телепортов HoYoLAB;
- sticky target, previous/next, skip, collected и undo;
- фильтры типов целей, постоянный blacklist и региональная сводка прогресса;
- компактный HUD, карточка подсказки и полная карта;
- режимы нагрузки, автоматический backoff при `LOST`, пауза и управление из трея;
- офлайн SQLite-прогресс и кэш просмотренных подсказок;
- экспорт и импорт прогресса;
- необязательная ручная additive-синхронизация отметок HoYoLAB;
- diagnostic bundles для воспроизводимой диагностики проблем локализации.

## Поддерживаемые регионы

| Регион | Статус | Поддержка |
| --- | --- | --- |
| **Фонтейн** | **Supported alpha** | Поверхность, 59 подземных этажей, POI, HUD, hints, progress |
| **Сумеру — пустыня** | **Experimental** | Поверхность, POI, HUD, hints, local progress |

**Фонтейн** — основной поддерживаемый vertical slice текущей alpha.

**Сумеру** пока ограничен поверхностью пустыни и используется в том числе для проверки переносимости локализатора на другой визуальный домен.

В визуально бедных областях, особенно некоторых руинах, Navigator может временно перейти в `LOST`. Это намеренное поведение: при недостаточной уверенности трекер предпочитает потерять позицию, а не показывать уверенную неправильную координату.

## Системные требования

- Windows 10/11 x64;
- Genshin Impact в оконном или безрамочном режиме;
- NumPad необязателен: предусмотрено альтернативное управление `Ctrl+Alt`;
- рекомендуемая готовая конфигурация: 1920×1080, масштаб Windows 100%;
- Edge WebView2 — только для необязательного входа HoYoLAB;
- интернет нужен для первичной загрузки региона, обновлений, подсказок и sync, но не
  для обычной навигации после настройки.

Интернет требуется для первоначальной загрузки региональных данных, получения новых подсказок и синхронизации HoYoLAB. После настройки основная локализация и локальный прогресс могут работать без сети.

## Быстрый старт

1. Скачайте `GenshinNavigator-v0.1.1-alpha-windows-x64.zip`.
2. Сверьте SHA-256 с соседним файлом `.sha256`.
3. Распакуйте архив в обычную доступную для записи папку.
4. Для Фонтейна запустите `Start-Fontaine.cmd`.
5. Для экспериментального Сумеру запустите `Start-Sumeru-Experimental.cmd`.
6. Подтвердите загрузку необходимых региональных данных при первом запуске.

> **Не запускайте `GenshinNavigator.exe` непосредственно из ZIP.**

Navigator создаёт рядом с программой локальный каталог `datasets/local`, где находятся загруженные данные, пользовательский прогресс, кэш и другое локальное состояние.

Portable archive намеренно не содержит карт, POI, изображений подсказок или других
материалов HoYoverse. При первом запуске стартовый файл попросит разрешение и загрузит
нужные данные напрямую с endpoint'ов, используемых интерактивной картой HoYoLAB, в
локальный пользовательский кэш. Прерванная загрузка не заменяет последний рабочий
набор, а уже проверенные тайлы используются при повторном запуске вместо повторной
загрузки. Эти материалы не становятся частью MIT-лицензии Navigator.

### Региональные данные

Portable-архив намеренно **не содержит карты, POI, изображения подсказок и другие материалы HoYoLAB/HoYoverse**.

При первом запуске Navigator запрашивает подтверждение и загружает необходимые данные в локальный пользовательский кэш. Прерванная загрузка не должна заменять последний рабочий набор данных.

Загруженные сторонние материалы не становятся частью MIT-лицензии Genshin Navigator.

## Настройка миникарты

При первом запуске `.cmd` создаёт рабочий `config.json` для Фонтейна или
`config.sumeru.json` для Сумеру и предлагает загрузить данные региона. Готовые
значения используют миникарту `216×216`
с левым верхним углом `(57, 19)` для 1920×1080. Если разрешение или UI отличаются,
запустите `Configure-Minimap.cmd` и выделите полную окружность миникарты. Кадр
используется только в памяти и не сохраняется. Проверить готовность можно командой:

```powershell
GenshinNavigator.exe setup-status --config config.json --region fontaine
```

При необходимости ROI по-прежнему можно изменить вручную:

```json
"roi": {
  "left": 57,
  "top": 19,
  "width": 216,
  "height": 216
}
```

При первом запуске создаётся рабочий `config.json` для Фонтейна или `config.sumeru.json` для Сумеру.

Если у вас другое разрешение, масштаб Windows или расположение HUD, необходимо изменить секцию `roi`, чтобы она точно охватывала миникарту.

## Управление

Можно использовать NumPad либо альтернативы на клавиатуре без цифрового блока:

- `Num4` / `Num6` — предыдущая / следующая цель;
- `Num2` — временно пропустить цель;
- удерживать `Num5` одну секунду — отметить сундук собранным;
- `Num8` — отменить последнее действие;
- `Num0` — HUD / полная карта;
- `Num7` — раскрыть или закрыть подсказку;
- `Num1` / `Num3` — страницы текста подсказки;
- `NumDecimal` — разблокировать HUD для перемещения / закрепить;
- `NumAdd` — сохранить обезличенный diagnostic bundle;
- `NumMultiply` — приостановить / продолжить распознавание;
- `NumDivide` — переключить тип целей;
- `NumSubtract` — добавить текущую цель в постоянный blacklist;
- `Num9` — закрыть Navigator.

Альтернативное управление без NumPad:

- `Ctrl+Alt+←` / `Ctrl+Alt+→` — предыдущая / следующая цель;
- `Ctrl+Alt+↓` — временно пропустить, `Ctrl+Alt+↑` — отменить;
- удерживать `Ctrl+Alt+Space` одну секунду — отметить собранным;
- `Ctrl+Alt+M` — HUD / карта, `Ctrl+Alt+L` — перемещение HUD;
- `Ctrl+Alt+H` — подсказка, `Ctrl+Alt+PageUp/PageDown` — страницы;
- `Ctrl+Alt+P` — пауза, `Ctrl+Alt+F` — тип целей;
- `Ctrl+Alt+B` — blacklist, `Ctrl+Alt+R` — diagnostic report;
- `Ctrl+Alt+Q` — закрыть Navigator.

Закреплённый HUD не получает фокус и пропускает клики. Если клавиши работают на
рабочем столе, но не в Genshin, запустите Navigator и игру с одинаковыми правами.
Закрыть, приостановить или снова показать HUD также можно через значок Navigator в
области уведомлений Windows.

## HUD

Компактный режим показывает цель, прямолинейное расстояние, слой, состояние трекера и
north-up стрелку. Ниже показаны частота CV, время последней обработки, выбранный режим,
фильтр целей и прогресс региона. При `LOST`, stale-позиции или телепорте цель сохраняется, но стрелка
и расстояние замораживаются и затемняются.

`Num7` открывает карточку точки из интерактивной карты HoYoLAB. Уже просмотренные материалы могут использоваться из локального кэша.

Недоступность HoYoLAB не должна останавливать основной GPS.

## Прогресс и офлайн-режим

Основное пользовательское состояние хранится локально:

```text
datasets/local/data/genshin_navigator.db
```

Прогресс сохраняется между запусками. Portable-релиз не содержит чужих баз данных, cookies, пользовательских diagnostic reports или прогресса.

Основная локализация после первоначальной настройки не требует постоянного подключения к интернету.

### Экспорт и импорт

При запуске проекта из исходников:

```powershell
.venv\Scripts\genshin-navigator progress-export progress.json --config config.example.json --region fontaine

.venv\Scripts\genshin-navigator progress-import progress.json --config config.example.json --region fontaine
```

Импорт объединяет поддерживаемые данные с существующим локальным состоянием.

## Неофициальная интеграция HoYoLAB

Интеграция с HoYoLAB **необязательна**.

Вход выполняется через отдельный профиль Edge WebView2. Navigator не должен читать cookies из установленного пользовательского браузера.

```powershell
GenshinNavigator.exe hoyolab-login --config config.json

GenshinNavigator.exe progress-sync --config config.json --region fontaine

GenshinNavigator.exe hoyolab-logout --config config.json
```

Перед синхронизацией показывается preview и требуется подтверждение.

Sync работает по additive-модели: Navigator может добавлять отметки, но не снимает их автоматически.

Важно: синхронизируются **отметки интерактивной карты**, а не фактическое состояние сундуков в игровом мире.

Интеграция использует неофициальные web-интерфейсы, используемые HoYoLAB Interactive Map. Это не поддерживаемый публичный API или SDK, поэтому формат и поведение могут измениться без предупреждения.

Отказ этой интеграции не должен мешать локальной навигации и прогрессу.

## Diagnostics и приватность

`NumAdd` создаёт diagnostic bundle для анализа проблем локализации.

Из командной строки:

```powershell
GenshinNavigator.exe diagnostic-record --config config.json --duration 5
```

Диагностика предназначена для сохранения последовательности **crops миникарты**, а не полного изображения экрана.

Diagnostic bundle не должен содержать:

- полный screenshot экрана;
- HoYoLAB cookies;
- authorization headers;
- игровой UID;
- полный пользовательский config;
- абсолютные пользовательские пути.

Перед публикацией или отправкой diagnostic bundle рекомендуется самостоятельно проверить его содержимое.

Никакие diagnostic bundles не отправляются разработчику автоматически.

В `datasets/local` вне Git могут храниться SQLite-прогресс, профиль HoYoLAB, кэш изображений, положение HUD, screenshots, сценарии и diagnostics.

## Известные ограничения

- Это ранняя alpha, а не завершённый продукт.
- Основная проверенная конфигурация — 1920×1080 при Windows scaling 100%.
- Сумеру пока экспериментален и ограничен поверхностью пустыни.
- В sparse / low-observability областях возможен `LOST`.
- Расстояние в некоторых экспериментальных coordinate spaces может быть некалиброванным.
- Направление к цели пока не учитывает стены, перепады высоты, входы в пещеры и реальный пеший маршрут.
- Скрытые, сюжетно заблокированные или уже собранные без отметки цели могут потребовать ручного `skip`.
- Изменения интерфейса игры или интерактивной карты могут потребовать обновления Navigator.
- Глобальные горячие клавиши могут конфликтовать с другими приложениями.
- Совместимость с другими разрешениями, DPI, графическими настройками и multi-monitor конфигурациями пока не гарантируется.

## Troubleshooting

### Tracker постоянно показывает `LOST`

1. Проверьте разрешение и Windows scaling.
2. Проверьте `roi` в конфигурации.
3. Убедитесь, что миникарта полностью находится внутри ROI.
4. Закройте большую карту игры и дождитесь появления обычной миникарты.
5. Убедитесь, что запущена конфигурация правильного региона.

### Navigator не показывает цели

Проверьте наличие данных региона в:

```text
datasets/local/poi/
```

При запуске из исходников состояние данных можно проверить командой `data-status`.

Navigator намеренно не выбирает POI другого региона.

### Не работают NumPad-клавиши

- Включите Num Lock.
- Используйте альтернативные комбинации `Ctrl+Alt`, если NumPad отсутствует.
- Проверьте одинаковый уровень прав Genshin и Navigator.
- Закройте программу, занявшую ту же глобальную клавишу.

### HoYoLAB недоступен

Основной GPS можно продолжать использовать офлайн.

Для login требуется актуальный Microsoft Edge WebView2 Runtime. Ошибка сети или HoYoLAB не должна повреждать локальный прогресс.

## Разработка из исходников

Проверенная среда: Python 3.12, NumPy 2.5.2, OpenCV 4.14.0, Pillow 11.3.0,
pywebview 6.2.1 и pystray 0.19.5.

```powershell
python -m venv .venv

.venv\Scripts\python -m pip install -r requirements-lock.txt
.venv\Scripts\python -m pip install -e .

.venv\Scripts\python -m unittest discover -s tests
.venv\Scripts\python scripts\release_smoke.py
```

### Подготовка регионов

```powershell
.venv\Scripts\genshin-navigator setup-region `
  --config config.example.json `
  --region fontaine

.venv\Scripts\genshin-navigator setup-region `
  --config config.sumeru.example.json `
  --region sumeru_desert
```

### Запуск

```powershell
.venv\Scripts\genshin-navigator track `
  --regions regions.json `
  --region fontaine

.venv\Scripts\genshin-navigator track `
  --regions regions.json `
  --region sumeru_desert
```

### Обновление данных

```powershell
.venv\Scripts\genshin-navigator sync-data --config config.example.json

.venv\Scripts\genshin-navigator sync-data --config config.sumeru.example.json
```

Обновление выполняется отдельно от основного runtime и должно заменять рабочие данные только после успешного завершения операции.

### Сборка portable release

```powershell
.venv\Scripts\python -m pip install -r requirements-build.txt

powershell -ExecutionPolicy Bypass -File release\build_portable.ps1
```

Release pipeline не должен включать карты HoYoLAB, POI, hint-cache или пользовательское состояние.

Сборка также включает third-party license texts, выполняет release/privacy checks и создаёт SHA-256 для итогового архива.

## Производительность

`v0.1.1-alpha` повторно использует признаки одного crop миникарты между уровнями
эталона и выбирает локальные признаки атласа векторно. На сохранённом surface-
сценарии разработчика средняя обработка кадра уменьшилась с `53.88 мс` до
`15.19 мс`, P95 — с `63.58 мс` до `17.98 мс`, без изменения CV-порогов,
coverage или false-lock результата. Фактическая нагрузка зависит от CPU, режима
окна, разрешения и состояния `TRACKING/LOST`. По умолчанию режим `balanced`
выполняет дорогой CV реже, чем обновляет HUD, а повторные неудачные глобальные поиски
получают постепенный backoff. В `performance.mode` доступны `quality`, `balanced` и
`low_cpu`; `NumMultiply` полностью приостанавливает захват и CV. При высокой нагрузке
приложите diagnostic bundle и данные из Диспетчера задач.

## Архитектура

```text
Screen Capture
      ↓
Minimap Gate
      ↓
Localization
      ↓
Stateful Tracker
      ↓
Position Model
      ↓
Navigation ─────────→ HUD
      ↑
Repositories
      ↑
SQLite
      ↑
Providers
      ↑
Region Manifest
```

CV-слой не зависит от HoYoLAB, пользовательского прогресса или SQLite.

Navigation работает с локальным состоянием и не требует сетевого доступа для определения текущего положения.
